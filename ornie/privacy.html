Personvern i Ørnie

Ørnie er laget for familier som vil ha bedre oversikt over oppdrag, regler, månedslønn og hverdagsansvar. Dataene brukes for å levere funksjonene i appen.

Data appen kan lagre

  • Navn, e-post og bruker-ID for innlogging og familiekobling.
  • Familier, roller, barneprofiler, regler, oppdrag, frister og oppgjør.
  • Bilder som legges ved oppdrag eller hendelser.
  • Teknisk informasjon som push-token og enkle bruksdata for appfunksjoner.

Hvordan data brukes

Data brukes til å vise riktig familieinnhold til riktige brukere, sende varsler, håndtere oppdrag og lage oversikt over månedssaldo og oppgjør.

Deling

Familieinnhold deles bare med brukere som er koblet til samme familie eller er invitert inn med riktig rolle. Ørnie selger ikke persondata.

Lagring

Appdata lagres i Supabase. Bilder kan lagres i Cloudflare R2. Tilgang styres med innlogging og familietilknytning.

Kontakt

Spørsmål om personvern kan sendes til earnie@navikite.com.
