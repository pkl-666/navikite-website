Slik fungerer det

Alt familien avtaler, samlet ett sted.

Foreldre setter rammer, barn ser hva som teller, og oppdrag kan dokumenteres med bilde. Ørnie er laget for hverdagsøkonomi i familien, ikke kompliserte budsjetter.

1

Regler og saldo

Sett grunnbeløp, tillegg og trekk som blir synlige underveis i måneden.

2

Oppdrag

Legg ut småjobber med frist, beløp og bilde. Barna kan claime og levere.

3

Bildebevis

Foreldre kan godkjenne, kommentere eller be om endringer for leverte oppdrag.

4

Oppgjør

Se historikk og månedsoppgjør med tydelig oversikt over hva som er opptjent.

For hele familien

Bygget for foreldre, tenåringer og hjelpsomme slektninger.

ForeldreFår oversikt over avtaler, frister, bildebevis, månedslønn og oppgjør.
TenåringerSer saldo, oppdrag og konsekvenser tydeligere, uten at alt må tas muntlig hver gang.
SlektKan inviteres til å legge ut egne oppdrag med direkte belønning.
